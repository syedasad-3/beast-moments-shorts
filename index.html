Beast Moments Shorts

Beast Moments Shorts is a personal, non-commercial automation project that creates short-form video clips from long-form video content and publishes them to a single YouTube channel operated by the project owner.

The application connects to the operator's own Google account to:

  • Read source video files the operator has placed in a designated Google Drive folder
  • Process and upload finished short-form videos to the operator's own YouTube channel
  • Check basic performance metrics (views, watch time) for videos it has uploaded

This application does not collect data from, or act on behalf of, any user other than its operator. It has no public sign-in or account creation — it is a private automation tool for one channel.
