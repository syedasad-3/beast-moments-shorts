Privacy Policy

Effective date: August 25, 2026

This privacy policy explains how BeastMomentsShorts ("the application," "we," "our") accesses, uses, and protects data when it connects to your Google account via Google OAuth. This application is operated as a personal automation project and is not a commercial product.

1. What the application does

BeastMomentsShorts is an automated pipeline that processes video content and publishes short-form videos to a YouTube channel on behalf of its operator. It runs on a schedule using Google Cloud APIs.

2. Google user data we access

The application requests the following Google OAuth scopes, and no others:

  • https://www.googleapis.com/auth/drive.file — access only to files this application creates or that the user explicitly opens with it in Google Drive. The application cannot see, list, or modify any other files in the user's Drive.
  • https://www.googleapis.com/auth/youtube.readonly — read-only access to check the operator's YouTube channel and video metadata (e.g., to avoid duplicate uploads).
  • https://www.googleapis.com/auth/youtube.upload — used solely to upload finished video files to the operator's own YouTube channel.

3. How the data is used

Data accessed through these scopes is used exclusively to:

  • Retrieve source video files that the operator has placed in a designated Google Drive folder.
  • Upload processed short-form videos to the operator's own YouTube channel.
  • Check whether a video has already been processed, to avoid duplicate publishing.

No data obtained through these scopes is sold, rented, or shared with any third party. No data is used for advertising purposes.

4. Data storage and retention

OAuth tokens are stored as encrypted secrets within GitHub Actions (a private secrets store, not visible in source code or logs) and are used only by the automated pipeline. Video files retrieved from Drive are processed temporarily during each automation run and are not retained beyond what is needed to complete the run and are periodically deleted from Drive as part of routine storage cleanup.

5. Third-party services used

Parts of the video-processing pipeline (transcription, content analysis, text-to-speech) may use third-party AI service providers. Only the video/audio content itself is sent to these providers for processing — no Google account data, credentials, or personal identifying information is shared with them.

6. Data security

All credentials (OAuth client secrets, API keys, refresh tokens) are stored using GitHub's encrypted Secrets mechanism and are never committed to source code or exposed in logs.

7. Revoking access

The Google account owner can revoke this application's access at any time via Google Account → Security → Third-party access.

8. Changes to this policy

This policy may be updated periodically. Material changes will be reflected on this page with an updated effective date.

9. Contact

For questions about this policy, contact the application operator via the email associated with the GitHub repository for this project.

This is a personal/non-commercial automation project. This policy is provided to satisfy Google API Services User Data Policy requirements for OAuth verification.
